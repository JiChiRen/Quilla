# Logo

Quilla has its own brand mark and wordmark. The full asset set and usage
rules — file inventory, sizing and clear-space rules, the single gradient
(`#34d399` → `#22d3ee` → `#8b5cf6`), single-colour reproduction, and the
brand-licence boundary — live in the canonical brand manifest:

> [`doc/images/README.md`](../images/README.md)

## Assets

All vector sources and the two rasterised assets are under `doc/images/`:

| File | Use |
| --- | --- |
| `quilla-mark.svg` | README header, slides, any place that needs the mark alone |
| `quilla-logo.svg` | Light backgrounds: site header, print, e-mail signature |
| `quilla-logo-dark.svg` | Dark backgrounds (same lockup, light wordmark) |
| `quilla-mark-512.png` | Square avatar — GitHub organisation / user avatar (dark plate) |
| `quilla-social-preview.png` | GitHub repository social preview (1280 × 630) |
| `quilla-favicon.svg` | Favicon / small icon (legible down to 16 px) |
| `quilla-demo.gif` | Flashing demo used by the README |

The README header uses `quilla-mark.svg` directly, so it tracks the vector
source and stays crisp on any display.
